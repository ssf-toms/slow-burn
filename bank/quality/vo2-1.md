# VO2max 1: 5×2 min @ 110%

```intervals
Warmup
- 4m 50%
- 4m 60%
- 2m 70%
- 1m 105%
- 4m 55%

5x
- 2m 110%
- 2m 50%

Easy spin
- 10m 65%

Cooldown
- 5m 50%
```

Very hard. The last minute of each rep should be uncomfortable but repeatable. If you can't finish a rep in ERG, drop to 105% for the rest of the session and repeat this step next time.
