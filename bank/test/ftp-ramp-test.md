# FTP test: MyWhoosh Ramp Test

In MyWhoosh go to Workouts → Testing → Ramp Test. Ride it to failure; MyWhoosh suggests a new FTP. Afterwards, update FTP in both MyWhoosh and intervals.icu (Settings → Ride → Power level settings), and tell me at the Check-in. It's not pushed as a structured workout, because the MyWhoosh test calculates FTP itself.
