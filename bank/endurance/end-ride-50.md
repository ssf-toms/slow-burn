# Endurance 50

```intervals
Warmup
- 5m 50%
- 5m 60%

Main
- 35m 68%

Cooldown
- 5m 50%
```

Easy, conversational, nose-breathing pace. The ride should feel almost too easy; that's the point.

On a good-weather day, swap this for [run-easy-6-8](../endurance/run-easy-6-8.md).
